よくあるご質問

アカウントを削除したい

アプリ内の プロフィール → 設定 → アカウントを削除 から削除できます。 削除後、読書記録・レビュー等のデータは復元できません。

プッシュ通知が届かない

iOS の 設定 → 通知 → HonTalk で通知が許可されているか確認してください。 また、アプリ内の 設定 → 通知設定 でも種類ごとに ON/OFF を変更できます。

不適切な投稿を報告したい

レビューやユーザープロフィール画面から通報できます。 ブロック・ミュート機能も設定画面から利用できます。
